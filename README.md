# Lucía Parrilla — Portfolio

Sitio estático bilingüe listo para GitHub Pages.

## Publicación

1. Descomprimí el ZIP y subí su contenido a la raíz del repositorio. El archivo index.html tiene que quedar junto a styles.css, script.js y la carpeta assets.
2. En Settings → Pages, seleccioná Deploy from a branch. Elegí la rama donde subiste los archivos y la carpeta /(root). Guardá los cambios.
3. Cuando termine la publicación, abrí Visit site y compartí esa dirección por WhatsApp.

## Video de SAKE

Subí el video a la carpeta `assets` con el nombre exacto `Showreel Sake (1).mp4`. El reproductor ya está configurado y usa la portada original.
